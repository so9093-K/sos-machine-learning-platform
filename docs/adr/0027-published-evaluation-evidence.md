# 0027 — 제공 모델의 공개 평가 근거

- 상태: **Accepted**
- 관련: [Experience](../experience.md#모델-활용), [Contracts](../contracts.md#권한과-표시-설정), [ADR 0026](0026-public-data-import.md)

## 배경

모델 제공은 판본을 새 적용에 열 뿐 공급자의 평가를 공개하지 않았다. 그래서 사용자는 모델을 고르기 전에
"어떤 검토량에서 무엇을 얼마나 잡는지"를 알 수 없었고, 자기 데이터에 적용한 뒤에야 기대와 다른 결과를 만났다.
실측 예로 정상 트래픽에서 정한 임계값은 공격이 많은 날(CIC-IDS2017 수요일)에 재현율이 0.5%였고, 검토량을
점수 상위 30%로 늘리면 정밀도 87%·재현율 75%였다. 이런 근거 없이 모델을 쓰면 판정 기준을 잘못 믿게 된다.

## 결정

1. **명시적으로 공개한 평가만 보인다:** 모델을 소유한 계정이 그 판본의 점수로 만든 자기 평가 중 일부를 공개
   평가 근거로 지정한다(관리자는 열람 가능한 평가). 제공만으로는 어떤 평가도 공개되지 않는다.
2. **집계 요약만 공개한다:** 공개 근거는 공급자가 쓴 기준 데이터 설명과 판정 기준, 검토 대상 수·실제 이상·놓친
   이상·정밀도·재현율·F1·순위 지표다. 평가 Dataset·Scoring Result·관측값의 식별자와 내용은 공개하지 않으며
   그 소유권 검사는 그대로다.
3. **기준 데이터의 결과로 표현한다:** 화면은 공개 근거를 그 기준 데이터의 결과로 보이고 사용자 데이터의 성능·
   승인으로 표현하지 않는다. 여러 판정 기준을 나란히 보여 검토량과 포착의 관계를 판단하게 한다.
4. **목록을 통째로 지정·해제한다:** 지정은 판본마다 순서 있는 목록(최대 10개)이며 빈 목록은 공개를 모두
   거둔다. 지정·해제는 감사 기록에 남는다. 평가 판본은 불변이므로 공개 근거는 그 판본을 참조한다.

## 근거

평가 자체는 이미 불변 판본과 집계로 남는다. 공개 여부만 공급자의 명시적 결정으로 두면 비공개 평가와 데이터
소유권을 지키면서, 사용자가 모델을 고르고 판정 기준을 정하는 데 필요한 근거를 줄 수 있다.

## 영향

- `model_offering_evaluations` 테이블, `PUT /api/ml/models/{id}/offering/evaluations`가 추가되고 제공 상태
  응답에 `published_evaluations`가 생긴다.
- 모델 상세의 공개 평가 근거와 지정 화면, 주제 화면 모델 카드의 공개 근거 요약이 추가된다.
