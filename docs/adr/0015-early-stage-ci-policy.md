# 0015 — 초기 단계 CI의 빠른 기본 경로

상태: **Accepted** · [ADR 0013](0013-lean-validation-policy.md)의 PR 핵심 통합·브라우저 필수 실행 및 `main` 전수 실행 결정을 대체한다.

## 배경

개발 초기에는 변경이 잦고 제품 계약도 함께 진화한다. 필수 DB/S3·브라우저 검증은 테스트 본문보다 환경 준비에 더 큰 비용을 소모하며, 중요하다는 이유만으로 매 변경마다 실행할 근거가 부족하다.

## 결정

- PR과 `main` push의 자동 검사는 Ruff·인프라 없는 Python·프런트엔드·생성 타입·API 호환성 등을 직접 실행하는 단일 `python-quality` Job만 사용한다.
- 실제 DB/S3 통합과 격리 브라우저 전체 검사는 `workflow_dispatch` 또는 로컬에서 **필요하다고 판단한 경우에만** 실행한다. 특정 변경에 대체 검사나 추후 전수 실행을 자동으로 요구하지 않는다.
- 브랜치 보호의 `python-quality` 이름은 유지하되, 고비용 Job의 성공을 집계하기 위한 별도 결과 판정 Job은 제거한다. Runner의 실패는 그대로 실패로 처리한다.

## 영향

기본 CI의 비용은 감소하지만 실제 DB·외부 저장소·브라우저 문제는 자동 PR 검사에서 검출되지 않을 수 있다. 이는 현 단계에서 수용하는 명시적인 선택이며, 추후 실제 결함 탐지 효과가 확인될 때만 자동 범위를 확대한다.
