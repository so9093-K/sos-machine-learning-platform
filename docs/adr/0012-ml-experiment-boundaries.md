# 0012 — ML 실험·이상 점수·외부 추적의 책임 경계

- 상태: Accepted · 관리 정본·외부 Tracking 항목(6·7)은 [ADR 0015](0015-mlflow-management-ownership.md)가 대체
- 범위: 첫 Isolation Forest 실험과 이후 모델 계열의 공통 도메인 계약
- 관련 기준: [Contracts](../contracts.md), [Runtimes](../runtimes.md), [Workflows](../workflows.md)

## 배경

SOS는 Dataset·Job/Attempt·객체 게시·권한의 정본을 보유한다. 첫 이상 탐지 모델을
추가하면서 프레임워크 점수, 모델 판본, 정책 임계값, 평가, 설명, 외부 Tracking Run을
단일 객체로 취급하면 학습 없는 정책 재평가와 재현성·복구가 어려워진다.

## 제안 결정

1. **작업과 알고리즘 분리:** 학습·점수 산출·평가처럼 실행의 의미와
   Isolation Forest 같은 알고리즘 종류를 구분한다. 단일 Job은 Workflow 없이도 실행한다.
   처음부터 범용 DAG·사용자 코드 플러그인을 도입하지 않는다.
2. **모델 판본:** 학습된 추정기·학습 전처리·입력 서명·런타임 호환성·아티팩트 무결성을
   하나의 불변 참조로 연결한다. 저장 사실만으로 모델 로딩의 안전성을 주장하지 않는다.
3. **점수:** 원본 프레임워크 점수와 SOS에서 표현하는 이상 점수 방향을 구분한다.
   Isolation Forest의 `score_samples`는 낮을수록 이상이므로,
   기본 SOS 이상 점수는 부호를 바꿔 높을수록 이상으로 정의한다. 점수는 확률이 아니다.
4. **판정 정책:** Model Revision과 Threshold/Decision Policy Revision을 분리한다.
   정적 및 참조 분위수 경계의 선택·적용은 동일한 점수 결과에 반복할 수 있다.
   현재 구현의 분위수 경계는 같은 Scoring Result의 점수를 참조한다. 동점 때문에
   실제 경보 비율을 보장하지 않으며, 참조한 Scoring Result 판본을 보존한다.
5. **평가:** 레이블 없는 평가에 감독 지표를 만들어 넣지 않는다. 레이블이 있을 때에도
   검증 집합과 최종 평가 집합이 구분되지 않은 지표는 독립 검증 성능으로
   해석하지 않으며, 분모가 0인 지표는 미정의로 표시한다.
   설명은 학습 Feature의 참조 중앙값 치환에 대한 점수 민감도를 기록한다.
   가법적 기여도나 인과적인 업무 원인의 증명으로 해석하지 않는다.
6. **SOS 정본:** 데이터, Job/Attempt의 최종 상태, 필수 평가 결과, 모델 판본과
   보존 의도는 SOS의 정본으로 유지한다.
7. **MLflow 선택 연결:** 외부 Tracking은 전송 상태·외부 Run ID를 가진 선택적
   어댑터로 다룬다. 외부 기록 실패가 성공한 학습을 실패로 바꾸거나 데이터를
   조용히 유실한 것처럼 숨기지 않으며, 원자적 양쪽 커밋을 주장하지 않는다.
   외부 Registry를 모델 판본의 정본으로 채택할지는 별도 검증 후 결정한다.

## 근거

모델 학습과 평가·정책 선택·설명은 서로 다른 재실행 비용과 데이터 요구가 있다.
도메인 판본과 저장소·추적 구현을 분리해야 다른 학습 모델과 외부 실행기를 도입해도
공통 결과와 권한의 의미가 변하지 않는다.

## 영향 및 구현 경계

첫 Isolation Forest 실험은 데이터·Model Revision·Scoring Result·Decision Policy·
Evaluation·Explanation의 판본을 독립적으로 보존한다. 점수 방향·레이블·임계값의
의미를 구분하고, Job/Attempt 완료·취소 및 객체 게시 상태를 공통 정본에 기록한다.

외부 MLflow 연결은 선택적 전송으로 취급하며, 내부 결과의 성공과 외부 기록의 성공을
혼동하지 않는다. 모델 파일은 내부 Worker가 생성한 신뢰된 Attempt에서만 복원하고,
임의 사용자 모델 업로드·범용 Model Registry·온라인 Serving을 이 결정의 구현으로
주장하지 않는다.
