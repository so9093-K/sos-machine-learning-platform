# 0016 — 변경 영향 기반의 최소 실제 계약 검증

상태: **Accepted** · [ADR 0015](0015-early-stage-ci-policy.md)의 PR 실제 DB/S3 검증 전면 수동화 결정을 대체한다.

## 배경

SOS는 독립된 PostgreSQL·S3·Iceberg에서 결과를 게시한다. 빠른 단위·타입 검사만으로는 이 저장소 간 경계를 확인하지 못한다. 반대로 모든 PR에 통합 148건과 브라우저 36건을 실행할 이유도 없다. 이전 CI 실측에서 전체 통합 183.83초, 브라우저 47.2초(테스트 실행 시간)가 소요됐다.

## 결정

- 기존 필수 상태 이름 `python-quality`을 유지하고 Ruff·단위·프런트엔드·생성 타입 및 PR OpenAPI 비교를 먼저 실행한다.
- PR의 Backend 코드·통합 테스트·환경 구성·CI 파일이 변경된 경우에만 **기존** 파일 등록·변환 Job 게시·Iceberg Snapshot·API 권한의 실제 PostgreSQL/S3 검사 네 건을 같은 Job에서 추가 실행한다. 선택한 검사의 실패는 해당 필수 상태를 실패시킨다.
- PR의 변경 경로는 Base와 검사 대상 Merge Commit의 Git diff로 확인한다. 해당 변경이 없으면 인프라를 준비하지 않는다. 경로 필터는 결함 검출의 완전한 증명이 아닌 초기 비용 절충이다.
- 전체 통합·브라우저 검사는 수동 선택 가능하게 남긴다. 새로운 메타 테스트 등록부·야간 전수 실행·테스트 개수 보충 의무는 만들지 않는다.

## 영향

핵심 저장소 간 계약에 대한 PR 자동 피드백을 회복한다. 네 건의 검출 범위를 벗어나는 회귀는 자동으로 발견하지 못한다. 유지 비용과 검출 실효를 관찰해 검사 대상을 변경할 수 있으며, 기존 ADR 0015의 자동 브라우저 제외·전체 실행 수동 선택 결정은 유지한다.
