# 0014 — Iceberg 과도기 쓰기 소유권 채택 종료

상태: **Proposed**

## 배경

[ADR 0008](0008-iceberg-table-write-ownership.md)은 쓰기 소유권이 기록되기 전의 테이블을 관리자 확인으로 채택하고 중단 시 재개하는 과도기 경로를 허용했다. 이 경로는 Catalog 토큰 변경·`Adopting` 상태·전용 CLI를 유지해야 하지만, 새 테이블의 정규 소유권 예약과 독립된 제품 기능은 아니다.

## 결정

- 테이블 Append는 동일 Actor·Catalog 토큰·물리 Table UUID가 확인된 기존 소유권에만 허용한다. Snapshot 읽기·보존 권한과 쓰기 권한은 별개다.
- 소유권이 불명확한 기존 테이블의 관리자 채택·자동 인수를 지원하지 않는다. 필요한 경우 권한이 확인된 원본 Dataset을 **새 테이블명**에 적재한다.
- 미완료 `Adopting` DB 행은 쓰기 불가 `Blocked`로 전환한다. 기존 Dataset·Snapshot·Tag·데이터 파일·감사 이력은 삭제하거나 임의로 소유권을 확정하지 않는다.

## 기존 결정과의 관계 및 영향

ADR 0008의 관리자 채택·중단 재개 결정만 대체한다. 신규 테이블 예약·권한 검증·Table UUID 확인과 쓰기 거부 원칙은 유지한다. 구형 테이블의 같은 이름 Append·채택 재개 기능은 사라지지만 읽기와 보존은 유지된다. 현재 동작의 정본은 [Contracts](../contracts.md#iceberg-테이블-쓰기-권한)이다.
