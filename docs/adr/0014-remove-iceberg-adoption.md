# 0014 — Iceberg 구형 테이블 쓰기 소유권 채택 경로 종료

상태: **Accepted** · [ADR 0008](0008-iceberg-table-write-ownership.md)의 관리자 소유권 채택 결정과 그 재개 절차를 대체한다.

## 배경

쓰기에 필요한 PostgreSQL Actor·Catalog 토큰·물리 Table UUID가 도입되기 전에 만들어진 테이블을 계속 수정할 수 있도록 별도 관리자 채택 CLI, `Adopting` 상태, Dataset 증거 컬럼, Catalog 토큰 변경과 재개 로직을 두었다. 이 과도기 기능은 일반 Iceberg 데이터·Snapshot 보존 계약과 달리 장기간 유지할 제품 기능이 아니다.

## 결정

- **신규 쓰기:** 정상적인 Job 제출로 예약된 테이블만 동일 Actor·토큰·Table UUID를 확인해 생성·추가 적재한다.
- **기존 소유권 불명 테이블:** 자동 또는 관리자 채택을 제공하지 않는다. 해당 Table의 기존 Dataset·Snapshot·Tag·데이터 파일은 그대로 두고 읽기와 보존 정책만 적용한다. 미확정 소유권으로 쓰기는 허용하지 않는다.
- **새 쓰기 경로:** 권한 있는 Actor는 기존 Dataset을 읽어 별도의 새 테이블명으로 적재할 수 있다. 기존 테이블을 덮어쓰거나 같은 이름으로 소유권을 재사용하지 않는다.
- **기존 DB 업그레이드:** 미완료 `Adopting` 행은 쓰기 불가 `Blocked` 상태로 보존한다. 증거용 `adoption_dataset_id` 컬럼과 채택 전용 실행 코드를 제거한다. 업그레이드 중 소유권을 확정하거나 S3·Iceberg 파일을 지우지 않는다.

## 영향

운영자 채택 CLI와 재개 기능은 지원하지 않는다. 신규 테이블 예약·활성화와 기존 테이블의 쓰기 거부·Snapshot 참조는 유지한다. 이전 채택 전용 감사 이벤트는 이미 기록된 데이터로서 보존하며, 새로운 채택 이벤트는 발생하지 않는다. 현재 쓰기 계약의 정본은 [Contracts](../contracts.md#iceberg-테이블-쓰기-권한)이다.
