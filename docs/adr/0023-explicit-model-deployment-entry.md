# 0023 — 모델 상세의 명시적 최초 배포 진입

- 상태: **Accepted**
- 대체: [ADR 0019](0019-ray-serve-online-serving.md) 결정 9의 웹 조작 범위

## 배경

등록 Pipeline 결과를 검토한 운영자가 모델을 제공한 뒤에도 최초 온라인 배포는
공급 스크립트·API에서만 요청할 수 있어 모델 상세와 운영 화면 사이가 끊겼다.

## 결정

모델 상세에서 기존 권한·Registry·자원 수용 계약을 통과한 판본의 최초 Endpoint 배포를
명시적으로 요청할 수 있다. 요청 접수와 실제 준비 완료를 구별하고 기존 온라인 서빙 운영으로 연결한다.
모델 제공 상태를 자동으로 바꾸거나 새 판본 전환·학습·공급 엔진을 추가하지 않는다.
배포·제공·학습은 계속 독립 작업이며 새 관리 저장소를 만들지 않는다.
