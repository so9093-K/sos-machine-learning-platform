# 0013 — 레거시 검증 자동화 초기화

상태: **Accepted**

## 배경

기존 검증 코드·Suite 관리·증거 재판정·CI 결합은 현재 개발 단계에서 이해와 유지보수가 가능한 수준을 넘어섰다.

## 결정

- 레거시 테스트, 전용 Fixture·실행기·관리 등록부, 기존 CI 자동 검증을 초기화한다. 기존 테스트에 대한 보존·일대일 대체 의무는 없다.
- 이 변경은 제품 코드, 데이터·모델 판본, 저장소 및 실행 계약을 초기화하지 않는다.
- 자동 검증 미실행과 삭제로 인한 위험을 사실 그대로 드러낸다. 새 검증 체계가 준비되기 전에는 제품 검증 성공을 주장하지 않는다.
- 이후 검증은 제품 비전과 검증 아키텍처 기준 이미지에서 출발하여 별도 PR에서 새로 설계한다. 기존 검증 구현은 신규 설계의 참고 기준이 아니다.

## 영향

ADR 0009의 레거시 검증 관리 결정을 종료한다. ADR 0011의 제품 Compose 실행·데이터 소유권 원칙은 그대로 두고 테스트 관리 관련 결정만 종료한다.
