# 0013 — 테스트 실행 비용과 필수 검증 정책 간소화

상태: **Accepted** · [ADR 0009](0009-test-engineering-portability.md)의 Inventory·Protected 등록·전체 JUnit 대조 결정을 대체한다. [ADR 0011](0011-compose-native-validation.md)의 Native Inventory·Protected Contracts 유지 결정도 대체한다.

## 배경

SOS는 모든 PR에서 실제 DB·S3·Iceberg 통합, 전체 브라우저 흐름, 별도 컨테이너 재시작 검증, 테스트 ID 인벤토리 대조까지 수행했다. 테스트 수 자체와 관리 메타데이터가 검증할 제품 위험보다 더 큰 유지·실행 비용을 만들었다.

## 결정

- 테스트 유무는 고유한 제품 결함 탐지 가치와 지속 비용으로 판단한다. 과거 존재·보호 등록·잠재적 위험만으로 영구 보존하지 않는다. 삭제에 반드시 대체 테스트를 요구하지 않는다.
- PR 필수 게이트는 Ruff·단위·프런트엔드·타입·API 호환성에 더해 실제 데이터·권한·Job 계약을 보호하는 **개별 핵심 통합 검증**과 소수의 브라우저 사용자 흐름을 포함한다. Python `pr`·Playwright `@pr`은 테스트 자체에 붙는 선정 표식이며 별도 보호 등록부나 Suite 실행기를 만들지 않는다. 전체 Python·브라우저 회귀는 main push·수동 실행에서 수행한다. 변경이 없는 날의 정기 전수 재실행은 제거한다. 브라우저 검사는 한 소유 Compose 프로젝트에서 실행한다.
- pytest·Vitest·Playwright·Ruff를 직접 실행하고 종료 코드와 Native 실행 로그를 검증 결과로 사용한다. 공통 Suite 실행기, JUnit·Manifest 재판정, 별도 테스트 ID 수집·Protected 선택자·전수 대조와 이를 보호하기 위한 테스트는 제거한다.
- 검증 실행기의 Docker 장애 주입·중복 컨테이너 런타임 검증은 제거한다. 소유 자원 외 삭제 금지, 실제 사용자 DB·버킷·Snapshot 보존은 실행 코드의 안전 경계로 유지한다.
- 위험도가 높은 DB·권한·데이터 손실 변경의 병합 전 추가 검증은 작업자가 실제 변경에 맞게 선택하고 PR에서 근거를 남긴다. 기존 전체 검증은 수동으로 실행할 수 있다.

## 영향

일반 PR은 선택된 실제 인프라·브라우저 계약을 자동 검증하되 전체 회귀를 실행하지는 않는다. 새 고유 위험을 변경할 때에는 관련 검증을 선택해서 확인해야 한다. 현재 실행 절차와 선택 기준은 [Testing & CI](../testing.md)를 따른다.
